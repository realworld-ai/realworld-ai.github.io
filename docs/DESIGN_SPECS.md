# The University of Osaka — Real-World Intelligence Infrastructure Lab — Design Specifications

## Project Overview
This document provides the design specifications for the visual identity system of the The University of Osaka Real-World Intelligence Infrastructure Lab website.

---

## (A) Logo Icon

### Design Concept
- **Core idea**: A central sphere represents "intelligence", three surrounding nodes represent the lab's infrastructure, and connecting lines signify interconnectivity.
- **Colors**: Blue gradient (primary) and white accents.
- **Style**: Modern, minimal, and easily recognizable.

### Current Assets

| File | Location | Usage |
|------|----------|-------|
| `logo_EN.png` | `/public/assets/brand/logo_EN.png` | Site header (nav bar logo) |
| `logo_background.png` | `/public/assets/brand/logo_background.png` | Hero section watermark (20% opacity) |
| `oldlogo_EN.png` | `/public/assets/brand/oldlogo_EN.png` | Previous version (archived) |
| `logo.png` | `/public/logo.png` | Favicon (referenced in Layout.astro `<link>` tag) |

### Specifications

#### SVG (Vector)
- **Files**: `/public/assets/logo.svg` (256×256), `/public/assets/logo-512.svg` (512×512) — if provided by vendor
- **Usage**: Favicon, digital media.
- **Properties**: Infinite scalability without quality loss.

#### PNG (Raster — generated by design vendor)
Please provide the following PNG exports with transparent backgrounds (PNG-32 with alpha):

| Size | Use | Notes |
|------|-----|-------|
| **512×512** | General use | Favicon, app icons, social profiles |
| **1024×1024** | High-DPI / backup | Retina displays, very large assets |

**Transparency note**: The logo background must be transparent; the mark itself should be fully opaque and sharply defined.

## (B) Logo + Lab Name (Lockup / Banner)

### Design Concept
- **Layout**: Icon on the left, English lab name on the right (three lines).
- **Colors**: Same blue tones as the logo; dark gradient background for contrast.
- **Typography**: Sans-serif (e.g., Arial or equivalent), bold, large sizes.

## (C) Homepage Hero Background

### Design Concept
The homepage hero uses a **fullscreen image slideshow** (HeroSlider.tsx) rather than a static background. 8 images rotate automatically with CSS opacity crossfade transitions.

### Current Hero Image Assets
Located in `/public/assets/hero/`:

| File | Description |
|------|-------------|
| `1.png` | Hero slide 1 |
| `2.png` | Hero slide 2 |
| `2-2.png` | Hero slide 2 variant |
| `3.png` | Hero slide 3 |
| `3-2.png` | Hero slide 3 variant |
| `4.png` | Hero slide 4 |
| `4-2.png` | Hero slide 4 variant |
| `openpackhaikei.png` | OpenPack background |

### Hero Layout
- **Overlay**: `bg-black/50` (50% black overlay via CSS for text contrast)
- **Global style override**: Overlay enhanced to `rgba(0, 0, 0, 0.7)` in Layout.astro
- **Content area**: Lab logo watermark at 20% opacity + lab name heading
- **Title sizing**: 3.5rem mobile → 4rem desktop, with text shadow for contrast

### Additional SVG Assets
| File | Location | Usage |
|------|----------|-------|
| `hero-background.svg` | `/public/assets/hero-background.svg` | Alternative/fallback SVG hero background (not currently active) |

**Important**: Dark overlays are implemented in CSS (not baked into images) so they can be tuned for accessibility.
